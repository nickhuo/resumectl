# Triage labels

| Label | Meaning |
|---|---|
| `needs-triage` | Scope and ownership have not been assessed |
| `needs-info` | Required facts or reproduction details are missing |
| `ready-for-agent` | Work is concrete and has a verifiable acceptance condition |
| `ready-for-human` | A human decision or action is required |
| `wontfix` | The project will not implement the request |

Use these existing names rather than introducing synonymous labels. Confirm issue context before changing its status.
