# Issue tracker

Use GitHub Issues for `nickhuo/resumectl` via `gh`.

```bash
gh issue list --repo nickhuo/resumectl
gh issue view <number> --repo nickhuo/resumectl
```

Use the existing issue when one is supplied. Issue descriptions should identify the affected domain, expected behavior and a verifiable acceptance condition. See [triage labels](triage-labels.md) for readiness. Do not mirror issues into another tracker.
